# Tamarind Table: concept website

A single-page site for **Tamarind Table**, a fictional trini kitchen and rum bar in Woodbrook.

Concept build by **Portside Digital**: websites that work. Tamarind Table is not a real business.

**Look:** Bricolage Grotesque + DM Sans, forest green with a scotch-bonnet red accent.

**Scroll animation** (GSAP + ScrollTrigger, switched off for people who prefer reduced motion):
- Hero headline rises word by word
- Framed photo zooms open to full-bleed on scroll
- Pinned horizontal menu pan
- Sticky story section where the photo follows the step in view
- Dish marquee that speeds up with scroll velocity
- Working table-booking form with guest stepper

Forms validate and show a success state, but don't send anywhere. On a client build they'd go to the owner's WhatsApp.
